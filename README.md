# 📖 لعبة تجويد تشالنج (Tajweed Challenge)

لعبة تعليمية تفاعلية شاملة لتعليم وإتقان أحكام التجويد بطريقة شيقة وممتعة للطلاب والمعلمين.

## ✨ المميزات الرئيسية
- 🎮 **مركز الألعاب (Game Center Arcade):** أنماط لعب متنوعة (تحدي كروت التجويد، تحدي المدرس، وضع الفرق، سباق السرعة).
- 👥 **نظام إدارة الطلاب (Student Roster):** تسجيل تقدم كل طالب، الشارات، سجل الأخطاء، وبنك المعالجة الفورية.
- 📜 **مكتبة أحكام تجويد شاملة:** تغطي جميع الأحكام (النون والميم المشددتان، القلقلة، أحكام الميم الساكنة، أحكام النون الساكنة والتنوين، التفخيم والترقيق، أحكام المدود، همزة الوصل، اللام الشمسية والقمرية، علاقات الحروف).
- 🔊 **نطق صوتي للآيات القرآنية:** بصوت الشيخ الحصري رحمه الله.
- 📱 **متجاوبة بالكامل:** تعمل بكفاءة على الحواسيب، الهواتف الذكية، والشاشات التفاعلية.

## 🚀 التشغيل المباشر
افتح ملف \index.html\ في أي متصفح، أو عبر خدمة **GitHub Pages**.
